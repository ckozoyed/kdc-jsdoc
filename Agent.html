Class: Agent

Agent()

Base class representing a KDC software Agent. An Agent encapsulates routing information and application data exchanged between KDC endpoints. KDC-JS follows the KDC-Java Agent wire contract to maintain serialization compatibility between implementations. The receiving endpoint must have the corresponding Agent implementation available locally. KDC does not transmit executable class definitions. Runtime concerns such as clients, protocols, peers, replies, and serializers are managed separately and are not part of this class.

Constructor

new Agent()

Creates a new Agent with a unique identifier and initialized wire-contract properties. The Agent is initially asynchronous and contains no visitor routing information or application data.
