Class: ClientParameters

ClientParameters(builder)

Configuration parameters shared by KDC-JS clients. Extends Parameters to provide the common configuration inherited by client-specific parameter classes. ClientParameters is intended to be extended by transport-specific client parameter classes rather than instantiated directly by application developers.

Constructor

new ClientParameters(builder)

Creates client configuration parameters from the supplied builder. Inherited configuration values are initialized by the Parameters constructor.

builder ClientParametersBuilder Builder containing the client configuration.
