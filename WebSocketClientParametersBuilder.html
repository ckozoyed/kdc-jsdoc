Class: WebSocketClientParametersBuilder

WebSocketClientParametersBuilder()

Builder for configuring KDC-JS WebSocket clients. Extends ClientParametersBuilder with WebSocket-specific configuration, including the server URL, synchronous Reply timeout, and event handlers. Inherits common configuration methods for compression, encryption, CRC checking, receive buffer size, and Agent class registration. Default WebSocket settings: - serverUrl: null (must be configured) - syncReplyTimeout: 7500 milliseconds - eventHandlers: empty array The builder is mutable and supports method chaining. Calling build() validates the required configuration and creates a WebSocketClientParameters instance.

Constructor

new WebSocketClientParametersBuilder()

Creates a builder with default WebSocket settings. Initializes the inherited client configuration and WebSocket-specific properties.
