Class: WebSocketClientParameters

WebSocketClientParameters(builder)

Configuration parameters for KDC-JS WebSocket clients. Extends ClientParameters with WebSocket-specific settings, including the server URL, synchronous Reply timeout, and registered event handlers. Instances are created using WebSocketClientParametersBuilder. The configuration object is frozen after construction to prevent reassignment of its properties. Note that Object.freeze() is shallow; referenced objects and arrays are not themselves frozen.
