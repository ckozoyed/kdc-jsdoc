Class: WebSocketClientEventHandlerAdapter

WebSocketClientEventHandlerAdapter()

Convenience adapter for handling KDC WebSocket client events. Provides empty implementations of the WebSocket client event callbacks. Applications may extend this class and override only the methods they need. Event callbacks are invoked by WebSocketClient during connection, transmission, and reception operations.
