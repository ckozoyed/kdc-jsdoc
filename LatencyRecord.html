Class: LatencyRecord

LatencyRecord(latencyContext)

Records latency measurement timestamps for a KDC Agent. A LatencyRecord maintains start and stop timelines for the latency metrics defined by its associated context. Each metric occupies a corresponding position in both timelines. The context determines the available metrics and their ordering. The startTimeLine, stopTimeLine, and latencyContext properties form part of the serialized KDC wire contract. The runtime context reference is maintained separately and is excluded from normal property enumeration.

Constructor

new LatencyRecord(latencyContext)

Creates a latency record for the specified context. Both timelines are initialized to zero for every metric defined by the context.
